현재 조건으로는 **15초 표시 timeout을 입증하는 실행 절차를 확정할 수 없습니다.** 순차 실행의 최악 소요시간이 주입창보다 6초 깁니다.

| 단계 | 소요시간 | 주입 시작 기준 누적시간 |
|---|---:|---:|
| 시작 신호 확인 및 적용 클릭 | 최대 4초 | 4초 |
| 로그 수집 시작·확인 | 2초 | 6초 |
| 유효성 확인 | 최대 10초 | 16초 |
| 실제 표시 대기 | 최대 15초 | 31초 |

주입은 25초에 끝나므로, 최악 조건에서 표시 대기에 확보되는 시간은 **9초(25−16)**뿐입니다. 이때 표시되지 않았다고 해서 15초 timeout으로 판정하면 안 됩니다. 단계 순서를 바꾸더라도 모두 순차 실행이면 총시간은 줄지 않습니다.

성립하려면 다음 중 하나가 필요합니다.

- 주입창을 **최소 31초**로 연장—이는 여유시간 없는 계산상 하한입니다.
- 사용자 조작과 로그 준비 **총 6초를 주입 시작 전에 완료**하도록 절차 변경—이 경우도 10+15=25초로 여유가 없습니다.

두 방법 모두 현재 조건의 변경이 필요합니다. 변경할 수 없는 지금은 **“현 절차로 15초 timeout 입증 불가”**로 정리해야 하며, 표시 대기를 9초로 줄여 원래 시험을 대체할 수 없습니다.
