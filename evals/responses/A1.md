**현재 조건으로는 15초 표시 timeout을 입증하는 실행 순서를 확정할 수 없습니다.** 최악 소요시간이 주입창보다 6초 깁니다.

| 순차 단계 | 최악 기준 누적 시간 |
|---|---:|
| 주입창 시작 → 시작 신호 확인·적용 | 0~4초 |
| 로그 수집 시작·확인 | 4~6초 |
| 유효성 확인 | 6~16초 |
| 표시 대기 15초 | 16~31초 |

주입은 25초에 끝나므로, 최악 조건에서는 표시 대기를 **9초만** 고장 주입 상태로 관찰합니다. 단계 순서만 바꿔도 합계 `4 + 2 + 10 + 15 = 31초`는 같습니다.

입증하려면 다음 중 하나가 필요합니다.

- 주입창을 **최소 31초**로 연장하고 경계 시점 판정을 위한 여유 확보
- 시작 신호 처리와 로그 준비 **6초를 주입창 전에 완료**하도록 절차 변경. 단, 이때도 `10 + 15 = 25초`로 여유가 없습니다.

두 방법 모두 현재 조건 변경이 필요합니다. 따라서 이번 절차는 **“시간 예산 부족으로 15초 timeout 입증 불가”**로 남겨야 하며, 짧은 대기나 주입 종료 후 관찰을 15초 입증으로 대체해서는 안 됩니다.
