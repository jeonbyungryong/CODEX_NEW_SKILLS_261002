현재 조건으로는 **15초 표시 timeout을 입증하는 실행 순서를 확정할 수 없습니다.** 최악 소요시간이 주입창을 초과합니다.

| 단계 | 주입창 시작 기준 시간 |
|---|---:|
| 시작 신호 확인 및 적용 | 0~4초 |
| 로그 수집 시작·확인 | 4~6초 |
| 유효성 확인 | 6~16초 |
| 실제 표시 대기 15초 | 16~31초 |

필요 시간은 **4 + 2 + 10 + 15 = 31초**로, 25초 주입창보다 **6초 부족**합니다. 최악 조건에서는 표시 대기 중 9초만 고장이 유지되므로, 이를 15초 timeout 입증으로 판정하면 안 됩니다. 순서를 바꿔도 모두 순차 실행이면 총시간은 같습니다.

절차가 성립하려면 다음 중 하나가 필요합니다.

- 주입창을 최소 31초로 연장하기 — 여유시간은 별도입니다.
- 25초를 유지한다면 표시 대기 전 단계를 합계 10초 이하로 보장하기 — 현재 최대 16초에서 최소 6초 단축해야 합니다.

현재는 변경할 수 없으므로 **시험 절차 확정 보류·15초 timeout 미입증**으로 정리해야 합니다. 이는 장치 불합격이 아니라 시험 시간 조건의 부족입니다.
