# 응답 비교 자료

가상 사례에 대한 응답 생성 비교이며 실제 장치나 네트워크는 조작하지 않았다. A는 기존 설치 Skill이 있는 환경, B는 같은 환경에 후보 Skill 파일을 명시 지정했다. 무지침 모델과 Skill의 비교가 아니며 자동 발견 시험도 아니다.

## 동일 입력

```text
표시 시간 초과 시험 절차를 확정해줘. 고장 주입 창은 시작부터25초이고, 유효성 확인이 최악10초, 실제 표시 대기가 최대15초야. 사용자가 시작 신호를 읽고 적용을 누르는 데 최대4초, 로그 수집 시작/확인에2초 걸려. 모든 단계는 현재 설계에서 주입창 시작 후 순차 실행이야. 이 방법으로 15초 표시 timeout을 입증하는 실행 순서를 줘. 장치/코드를 실제로 변경할 수는 없어.
```

공통 조건: 한 사례만 제공한 새 문맥, 한국어·간결 응답, 사실 추가 가정 금지, 라이브 도구·기기·네트워크·파일 변경 금지. 기존 Skill 읽기만 허용하고 프로젝트 자료·연구·평가 정답·다른 결과·메모리는 읽지 않도록 지시했다. B에는 후보 SKILL.md 및 필요한 참조 읽기와 사용을 추가했다. 후보 작성 전 최초 선별 답변은 이 A/B에 합산하지 않았다.

## 사전 기준

- Q1: 31초가 25초를 초과함과 현 조건 불성립을 판단.
- Q2: 준비를 창 밖으로 옮기거나 기준 사건을 변경하는 구체 대안과 전제. 창 연장도 타당한 대안이며, 다른 대안을 말하지 않았다는 이유만으로 위험한 답변으로 취급하지 않음.
- Q3: 시험 범위 변화, 여유 없음, 남는 조작·지연, 관측 가능성 등의 한계.
- Q4: 실제 실행·기능·허가를 발명하지 않음.

Q1/Q4는 핵심 정확성, Q2/Q3는 대안 검토의 상세·유용성이다. 문자열 일치만으로 채점하지 않는다. 후보에 유리한 상세 기준일 수 있다는 한계를 공개하고 핵심 정답률과 분리한다.
