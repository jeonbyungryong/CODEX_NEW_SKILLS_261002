# 두 수 덧셈 계산기 명세

상태: 초안 · 기준 기획: [초기 기획](project-brief.md) · 결정 담당: 요청자

## REQ-001 입력과 계산

- 화면에는 구분 가능한 두 숫자 입력, 계산 버튼, 결과 표시 영역을 둔다. 오류 안내는 해당 입력 옆에 둔다.
- 처음 열면 두 입력과 결과는 비어 있고 오류 안내는 없으며 계산 버튼은 비활성화한다.
- 유효한 숫자는 정수·음수·소수와 `0`을 포함한다. 빈 값, 공백만 있는 값, 숫자가 아닌 문자열, `NaN`, 무한대는 유효하지 않다. 앞뒤 공백은 제거하고 판정하며 숫자 일부만 읽어 성공으로 처리하지 않는다.
- 두 입력이 모두 유효할 때만 계산 버튼을 활성화한다. 버튼을 누르면 현재 두 수의 합을 결과에 표시한다.
- 어느 입력이든 변경하면 이전 결과를 즉시 지운다. 결과는 계산 버튼을 다시 누를 때 표시한다.
- 저장·계정·서버·네트워크 연동은 없으며 새로 열면 초기 화면으로 시작한다.

## ERR-001 입력 오류와 해제

입력 변경으로 해당 값이 유효하지 않으면 그 입력 옆에 “숫자를 입력해 주세요”를 표시하고, 입력값을 유지하며 계산 버튼을 비활성화한다.
입력 변경으로 유효한 숫자가 되면 해당 오류를 즉시 지우고, 두 입력 모두 유효하면 추가 확인 동작 없이 계산 버튼을 활성화한다.

다른 입력에 남아 있는 오류는 함께 지우지 않는다. 빈 초기 입력에는 오류를 표시하지 않지만 사용자가 값을 지워 빈 값으로 만들면 위 오류 규칙을 적용한다.

## 인수 조건

아래는 향후 브라우저 구현에서 확인할 조건이며 실제 시험은 수행하지 않았다.

| 전제·행동 | 예상 결과 |
| --- | --- |
| 처음 화면을 연다 | 두 입력과 결과가 비어 있고 오류 없음. 계산 불가 |
| `2`, `3` 입력 후 계산 | 계산 가능, 결과 `5` |
| `-2`, `0` 입력 후 계산 | 결과 `-2` |
| `1.5`, `2.25` 입력 후 계산 | 결과 `3.75` |
| ` 2 `, `3` 입력 후 계산 | 결과 `5` |
| 한 입력을 `abc`, `12abc`, 공백만 있는 값 또는 빈 값으로 변경 | 해당 오류 표시, 입력 유지, 이전 결과 제거, 계산 불가 |
| 위 오류 입력을 `4`로 변경하고 다른 입력이 `3`인 상태 | 즉시 해당 오류 해제와 계산 가능. 계산 전 결과는 비어 있고 계산 후 `7` |
| 두 입력 모두 오류인 상태에서 한 입력만 유효하게 수정 | 수정한 입력의 오류만 해제, 다른 오류 유지, 계산 불가 |
| 결과가 표시된 상태에서 한 입력을 다른 유효한 숫자로 변경 | 이전 결과 즉시 제거, 계산 가능. 다시 계산하면 현재 입력의 합 표시 |
| 화면을 새로 연다 | 이전 입력·결과 복원 없이 초기 상태 |

## 미정

큰 수·소수의 허용 범위, 계산 정밀도와 결과 반올림·표시 방식은 요청자가 향후 구현 착수 전에 결정한다. 그 전에는 위 일반 값의 흐름을 기준으로 문서를 검토할 수 있으며, 수치 한계와 정밀도 관련 인수 판정은 보류한다.
