# 사내 웹 메모 서비스 초기 기획

상태: 검토용 초안 · 기준일: 2026-10-15 · 결정 담당: 역할 지정부터 미정

## 목적과 성공

- 문제: 사내 사용자가 메모를 편집하고 서버에 저장할 때 연결 단절·응답 유실·인증 만료로 입력을 잃거나 저장 여부를 오인할 수 있다.
- 사용자와 환경: 계정으로 인증한 사내 사용자, 웹 브라우저, 중단될 수 있는 서버 연결.
- 핵심 동작: 메모 편집 → 저장 → 해당 계정·메모·편집본의 실제 저장 결과 확인.
- 성공 기준: 실패 중 입력 보존, 확인되지 않은 결과의 완료 표시 방지, 다른 계정으로 자동 전송 방지.
- 이번 산출물: 이 기획과 [저장 기능 명세](requirements.md). 정책 합의나 제품 실행 검증을 뜻하지 않는다.

## 운영 계약과 범위

| 결정 | 내용 |
| --- | --- |
| 반드시 포함 | 메모 편집·서버 저장, 상태 표시, 입력 보존, 결과 불확정 확인, 인증 만료·계정 변경 시 전송 경계 |
| 이번에 제외 | 앱 설치, 제품·시험 코드, 실제 서버 연결·배포·운영 데이터 변경. 공동 편집 등 추가 기능 기획 |
| 보호 자료 | 최신 입력, 미확인 저장본, 마지막 확인 정상본. 초안·대기 요청은 원래 계정에 귀속하며 다른 계정에 자동 전송·노출하지 않음 |
| 복구 행동 | 입력을 유지하며 동일 계정 재인증 후 같은 저장 건의 결과 확인·중복 없는 재시도. 자동 재시도 시간·횟수 미정 |
| 진행 제한 | 입력 소실·계정 간 전송·거짓 성공을 허용하지 않음. 미정 정책에 의존하는 구현 확정은 결정 후 진행 |
| 확인 범위 | 문서 일관성 확인만 가능. 종료 후 복구·서버 내구 저장·재시도의 실행 증거 없음 |
| 승인 범위 | 기획·명세 작성만 승인됨. 입력 소실이나 계정 간 자동 전송을 수용한 이력 없음 |

## 먼저 확인할 경로

편집 → 저장 대상본 고정 → 서버 내구 저장 → 같은 건의 결과 확인 → 최신 입력과 비교해 표시한다. 실패는 입력 보존 → 원인별 복구 → 저장 상태 재판정으로 연결한다.

| 우선 경로 | 위험·가정 | 최소 관측과 종료 조건 |
| --- | --- | --- |
| 정상 저장·추가 편집 | 이전 응답이 최신 입력까지 저장한 것으로 오인될 위험 | 응답과 대상 편집본 대응. 이후 입력은 미저장 유지 |
| 단절·응답 유실 | 서버 저장 후 응답만 잃을 수 있음 | 실패와 불확정 구분, 입력 보존, 같은 건 확인·중복 방지 |
| 만료·계정 변경 | 대기 메모가 새 계정으로 전송될 위험 | 전송 중단, 같은 계정 재인증 후 확인. 다른 계정 자동 전송·노출 없음 |
| 첫 메모 | 서버 정상본이 없을 수 있음 | 첫 실패에도 입력 유지. 첫 내구 저장 확인 후 정상본 생성 |
| 브라우저 종료·재실행 | 로컬 보존 정책 없이 복구를 약속할 위험 | 현재는 요구·미정 기록. 종료 후 보장은 정책·구현·검증 후 확정 |

## 미정 결정

담당 역할도 미정이다. 아래는 확정 담당자를 임의로 지정한 표가 아니다.

| ID·항목 | 결정 담당 | 결정 시점 | 그 전 진행 범위 |
| --- | --- | --- | --- |
| D-01 재시도 간격·응답 확인 기한·총 대기 기한·최대 횟수·수동 재시도 예산 | 역할 지정 미정 | 재시도 동작 설계 확정 전 | 조건·중단·중복 방지 계약 작성. 수치 확정·구현 보류 |
| D-02 종료 후 로컬 보존 범위·기간·접근 제어·삭제·로그아웃 처리 | 역할 지정 미정 | 로컬 저장 방식·종료 후 복구 보장 확정 전 | 실행 중 보존·계정 격리 요구 작성. 종료 후 영속 보존 보장 아님 |
| D-03 인증 만료 후 계속 편집 허용 여부 | 역할 지정 미정 | 만료 상태 편집 UI 확정 전 | 기존 입력 유지·전송 중단·같은 계정 재인증 계약 작성. 신규 편집 허용 여부 미확정 |
| D-04 정책 결정 역할·승인 경로·지원 담당 | 역할 지정 미정 | D-01~03 결정 착수 전 | 검토용 문서와 쟁점 작성. 승인·위험 수용으로 간주하지 않음 |

## 다음 행동

정책 담당을 지정하고 D-01~03을 합의한 뒤 명세를 갱신한다. 이후 별도 구현 요청이 있을 때 구현·검증 범위를 정한다. 이번 문서 작성에는 설치나 제품 구현이 포함되지 않는다.
