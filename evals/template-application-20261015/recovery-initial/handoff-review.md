# V2/H2 시범 운영 인계 검토

기준일: 2026-10-15 · 자료 성격: 문서 시험용 가상 기록. 아래는 제공된 근거의 판정이며 실제 서비스·저장소·브라우저를 확인한 결과가 아니다.

## 판정과 승인 범위

**V2/H2의 사내 소수 사용자 시범 운영 인계는 범위 한정 완료로 판정한다.** 운영 담당이 실제 복구 경로 미검증과 C2 원본 재현 공백을 명시적으로 수용하고 해당 범위의 운영을 승인했다. 승인 일자·담당자 실명은 제공되지 않았다.

수동 동일 계정 재로그인은 허용된 복구 행동이다. 자동 복구 보장, 전체 사용자 확대, 정식 출시, V2/H2의 실제 복구 시험 통과를 승인한 것으로 확대하지 않는다. 이번 판정은 문서상 인계이며 배포·설치·제품 수정 권한을 추가하지 않는다.

## 후보별 근거와 한계

| 대상 | 제공된 근거·실행 수준 | 판정과 증명하지 못하는 것 |
| --- | --- | --- |
| V1/H1 | 실제 브라우저 정상 저장 통과: 실제 대상 시험 | V1/H1 정상 저장에 한정. V2/H2 정상 저장·실제 복구의 통과 근거로 전용 불가 |
| V2/H2 | 정적 검사·저장소 모의 시험 통과 | 해당 검사·모의 범위만 확인. V2/H2 실제 브라우저 정상 저장 통과 근거도 제공되지 않음 |
| V2/H2 | 응답 유실·인증 만료 후 실제 복구 경로 미실행 | 미검증 유지. 수동 재로그인 허용은 동작 성공의 실행 증거가 아님 |
| V2 UI 번들 → C2 | 번들에 C2 표기. 인계 저장소 공개 refs 및 정확 SHA 조회로 원본 확보 실패 | 원본 접근·재현 공백. 표기는 원본 확보나 재빌드 동일성의 증명이 아님 |
| V2/H2 운영 승인 | 운영 담당의 명시적 위험 수용 | 위 미검증·공백을 수용된 제한으로 인계. 기술적 PASS로 바꾸지 않음 |

제공 자료만으로 현재 제품 결함을 확정하지 않는다. 반대로 실행하지 않은 경로를 정상으로 추정하지 않는다. H1/H2는 제공된 후보 식별이며 이번 검토에서 산출물 해시를 독립 검증하지 않았다. 원본 근거 파일·로그 위치도 제공되지 않았다.

기존 [기획](project-brief.md)·[명세](requirements.md)의 입력 보존·계정 경계와 D-01~04 미정은 유지한다. 시범 승인으로 재시도 수치·종료 후 로컬 보존·만료 후 편집 정책·정책 담당이 결정된 것은 아니다. 자동 복구 보장은 승인되지 않았다.

## 다음 일을 재개하는 조건

새 사건이나 자료가 없으면 기존 시범 승인과 범위 한정 완료를 유지하고 검토를 종료한다. 과거 미검증만을 이유로 동일 시험·조회나 설치 조사를 반복하지 않는다.

| 우선순위·재개 사건 | 바꿀 결정·최소 새 관측 | 담당·권한·상한 |
| --- | --- | --- |
| 1. 시범 중 입력 소실·계정 간 전송 또는 복구 불가가 보고됨 | 현재 운영 영향과 시범 지속 여부 판단. 해당 후보·계정 경계·사건 시각·본문/토큰 없는 최소 진단부터 확보 | 운영 담당이 운영 판단, 조사 실행 담당은 미정. 실제 조사·변경은 별도 범위 지정 후 진행 |
| 2. 복구 보장 또는 운영 확대를 새로 요청함 | V2/H2에서 응답 유실 뒤 저장 여부 확인·중복 방지·입력 보존, 만료 뒤 동일 계정 재로그인·재사용 및 다른 계정 자동 전송 차단을 실제 경로로 관측. 다른 후보라면 그 후보의 별도 근거 필요 | 운영 담당이 새 범위 승인, 검증 담당 지정 필요. 제안: 승인된 기존 환경에서 두 장애 시나리오 각 1회, 전체 2회까지. 같은 불확정 결과면 새 원인·관측법 확보 전 중단. 이번에는 실행하지 않음 |
| 3. 원본 재현·수정이 필요해지거나 C2를 가리키는 새 ref/원본 자료가 제공됨 | C2 원본 확보 여부와 V2 UI 번들과의 대응을 확인해 재현 공백 해소 가능성 판단. 공개 refs·정확 SHA의 기존 실패를 그대로 반복하지 않음 | 인계 원본 제공 담당 지정 미정. 제안: 새 자료에 대한 확보·대응 확인 1회. 여전히 불명이면 공백 유지·종료. 재빌드·새 환경 확보는 별도 요청 범위 |

위 제안의 전체 상한은 복구 시나리오 2회와 새 원본 자료 확인 1회다. 도구·리뷰 방법을 바꿔도 자동 증액하지 않는다. 실행 전에 담당·환경·권한을 정하며, 새 자료가 없어 재개 조건이 충족되지 않으면 기다린다. 기능 개선은 현재 운영 영향·입력/인증 안전·필요해진 원본 재현 공백 다음 순위다.

이번 수행은 제공된 가상 기록의 문서 판정뿐이다. 실제 시험·원본 확보·설치·배포·제품 변경은 하지 않았다.
