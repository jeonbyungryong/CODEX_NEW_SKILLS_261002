# DWG 적용 개인 Skills 점검

2026-10-07 · 현재 확보된 증거에 대한 검토. 미래 시점까지의 추가 관측이나 제품 공식 배포 완료를 주장하지 않습니다.

## 결론

| 대상 | 결정 | 확인 범위 | 제한 |
| --- | --- | --- | --- |
| PowerShell 인계 검증 | 유지 | 명시 로딩, 실패 전파 위험 발견, 실제 PowerShell 5.1 정상·고의 실패 처리, 두 엔진의 합성 계약 시험 | 타PC 전체 수용·이번 실제 작업의 적용 전후 인과 효과는 미검증 |
| 실기시험 조율 | 조건부 유지 | 최초 명시 로딩, 후속 행동과 준비·관측 분리 원칙의 부합 | 후속 GUI/공존 성공이 개인 Skill 때문이라는 인과 효과는 미검증 |
| Computer Use 신규 Skill | 생성 보류 | 공식 도구의 GUI 관측, 초기화 실패·재개·재대상 사례 | 기존 공식 지침 대비 추가 효과는 미입증 |

DWG 현재 PC에서 승인된 개발·검증·인계는 종료됐습니다. 다음 AutoCAD·타PC 실기는 다른 환경의 후속 작업입니다. Skills 효과의 미검증을 제품 미완료로 취급하거나 이미 완료한 CAD 시험을 반복하지 않습니다.

## 확인된 사실

DWG 작업의 기록을 읽어 대조했으며 이 문서 작성에서 제품·CAD·GUI 시험을 재실행하지 않았습니다.

- 제품 전체 시험 기록: 931 PASS / 13 SKIP. 이는 제품 suite의 결과이며 Skill 효과 시험 수가 아닙니다.
- 실제 GUI의 세 선택창, 주소 경로 조작, 단계별 취소와 두 입력 방식의 변환을 확인한 기록이 있습니다. CLI 성공과 GUI 수용을 따로 평가했습니다.
- 사용자 CAD를 유지한 공존 시험은 도면 7개 성공, 원본 보존과 APP 전용 CAD 종료를 확인했습니다.
- 최신 검증 키트는 312개 파일의 무결성을 확인했고 현재 PC의 PowerShell 5.1에서 실제 verify 진입은 exit0, EXE 누락 고의 실패는 exit1이었습니다. 전체 build 진입의 실패 주입이나 다른 PC 수용까지 입증한 것은 아닙니다.
- 개인 PowerShell Skill을 전체 읽은 호출과 뒤이은 키트 검증 행동이 확인됐습니다. 초기 적용 기록에는 검증 실패 후 ZIP 생성 위험 및 소스 인코딩/cwd 계약 위험 발견도 있습니다.
- 격리 표본에서 PS5.1 JSON 파이프라인 수집 Count1과 분리 파싱 Count3, PS7 Count3을 관측했습니다. 두 엔진의 11 schema 조건, Unicode/공백 argv와 의도적 native 실패 차단, 디코딩 경계를 확인했습니다. 실제 작업의 모델 행동 A/B는 아닙니다.

## 원인 계층과 비평

| 사례 | 분석 | 잘못 일반화하면 안 되는 결론 |
| --- | --- | --- |
| native 로그 UTF8 수집 실패 후 다른 인코딩 읽기 성공 | 출력 수집 경계의 계약 적용 필요 | 제품 변환 실패 또는 모든 native 출력의 동일 인코딩 |
| 도구 초기화/ACL 오류 뒤 공식 연결 재개 | 실행 환경·도구 계층 문제, 원인은 미확정 | 전역 권한 부족 확정 또는 Skill로 권한 복구 |
| 오래된 창 핸들/좌표 오류 | 최신 창과 화면 재관측으로 재대상 | 모든 UI 장애의 보편적 해결 |
| 구형 선택창 문제 후 승인된 새 구현 수용 | 제품/UI 경로 개선과 실기 관측 | 초기 도구 연결 오류의 근본 원인까지 규명 |
| CLI 뒤 별도 GUI 관측 | 증거 범위 구분 | 개인 조율 Skill의 인과 효과 확정 |

기존 PowerShell 본문은 종료코드·argv·독립 인코딩·실제 진입과 고의 실패를 이미 요구합니다. 규칙을 더 늘리기보다 실행 준비에서 이 계약을 선택하고 확인하는 적용 지점을 검토합니다. 실기 조율은 사람 행동과 agent 관측이 의존하는 상황에만 적용하며 무인 변환에 불필요한 시간 예산을 붙이지 않습니다.

## Computer Use 신규 Skill을 보류하는 이유

문제가 없어서 보류한 것이 아닙니다. 문제가 도구 초기화, 제품 선택창, 화면 재대상 등 서로 다른 계층에 있고, 새로운 개인 Skill이 기존 공식 지침보다 이를 개선한다는 근거가 부족합니다. 생성 자체로 연결·인증·권한·제품 버그를 복구할 수 없습니다.

기존 공식 지침과 중복되는 본문은 읽기·유지보수 부담이 늘어날 수 있습니다. 이는 분석상 리스크이며 실제 토큰 비용 측정 결과는 아닙니다. 필요성이 없다고 증명한 것도 아니며 영구 제외가 아닙니다.

재검토 조건은 다음과 같습니다.

1. 기존 지침을 읽은 조건에서도 같은 판단 누락이 반복됩니다.
2. 그 누락을 막는 구체적인 최소 추가 절차가 있습니다.
3. 동일 조건의 기준선/후보 비교에서 추가 절차가 오류·재작업을 줄입니다.

제품 시험 성공·연결 복귀·문서 읽기만으로 위 비교를 대신하지 않습니다.

## 미검증과 반영 경계

자동 Skill 선택 신뢰도, 이번 실제 프로젝트의 통제된 적용 전후 효과, 시간·토큰 절감률, 장기 안정성과 타프로젝트 일반화는 미검증입니다. 후속 turn에서 로딩 호출이 검색되지 않는다고 미사용을 확정하지 않습니다.

이번 반영은 비식별 검토 문서와 README뿐입니다. 기존 Skill 본문·설치·제품·브라우저 권한·태블릿은 변경하지 않습니다. 별도의 새 독립 리뷰어 또는 fresh-context A/B를 실시한 것으로 표현하지 않습니다. 연결/제어 후속 진단 결과도 아직 이 문서에 포함하지 않습니다.
