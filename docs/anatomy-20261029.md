## 설치와 사용

이 PC의 Codex 공용 스킬 폴더 `~/.codex/skills/anatomy`에 전체 설치했다. 다음 turn부터 `$anatomy`로 사용할 수 있다. 같은 PC 사용자 계정의 모든 Codex 프로젝트에서 발견 가능한 위치이며, 모든 작업에 무조건 호출하라는 뜻은 아니다. 다른 에이전트나 다른 PC에 자동 설치되지는 않는다.

다른 PC에서는 `skill-installer`로 이 저장소의 `skills/anatomy`를 설치하거나, [일괄 설치 안내](bulk-install.md)의 25개 목록을 사용한다. 기존 같은 이름의 사용자 수정본은 덮어쓰지 않는다.

```text
$anatomy 기계식 인터록이 동시에 두 동작을 막는 원리를 interactive SVG로 설명해줘.
```

Node.js 20.10 이상과 Chrome/Chromium이 필요하다. 별도 모델 API 키·Python·Linux·MCP 등록·npm 라이브러리 설치는 기본 사용의 필수 조건이 아니다. React 결과를 쓰는 경우 대상 프로젝트의 React 환경은 별개다. Codex 자체 사용량은 발생하며, 공개 게시와 유료 서비스 호출은 이 설치에 포함하지 않는다.

## 업데이트 연결

기존 매시간·수동 upstream 검사 workflow가 `bundle.json`의 Anatomy `main`을 확인한다. `layout: repository-root`를 지원해 전체 패키지의 지원 파일도 보존한다. 원본 변경은 검증된 리뷰 브랜치/PR로만 준비하며 main 병합과 기존 PC 설치본 갱신은 자동 실행하지 않는다.
