# 설치·사용 안내

## 먼저 파일로 시험하기

저장소를 받은 뒤 Codex에서 `skills/coordinate-device-validation/SKILL.md`를 파일로 첨부하거나 실제 저장된 전체 경로를 전달합니다. 이렇게 읽게 하는 시험은 전역 설치나 자동 선택과 다릅니다.

```text
첨부한 coordinate-device-validation SKILL.md를 사용해 아래 시험 계획을 검토해줘.
목표: 사용자가 기기 화면을 조작하고 agent가 수집을 담당하는 시험.
승인 범위: 절차 검토만. 실제 조작·코드 변경은 금지.
현재 상태: [기기/화면/연결/정상 기준]
시간 조건: [각 제한의 시작 사건, 종료 사건, 단계별 소요시간과 순차/병렬 여부]
관측 가능 항목: [사용자 화면, 응답, 로그]
복귀 방법: [이미 승인된 방법 또는 미정]
현재 조건으로 성립하는지, 다음 행동과 남은 한계를 간결하게 알려줘.
```

설치 후에는 파일 경로 대신 `$coordinate-device-validation`을 지정할 수 있습니다. 이름이 인식되지 않으면 먼저 설치 상태와 해당 환경의 사용 가능 목록을 확인합니다. 이 문서는 특정 앱 버전의 메뉴 위치를 추정하지 않습니다.

## 설치와 업데이트

README의 설치 요청을 Codex에 전달합니다. 설치 대상은 `skills/coordinate-device-validation` 폴더이며 `SKILL.md`와 `references/timing-budget.md`를 함께 유지해야 합니다. 기존 동일 이름 폴더가 있으면 차이를 검토하고 원본을 보존한 뒤 업데이트 여부를 결정합니다. 환경별 설치 위치·재로딩 절차는 실제 설치 도구의 안내를 따릅니다.

Skill은 사용 조건을 설명하는 metadata와 실행 시 읽을 지침·참조를 묶는 형태입니다. 참조만 따로 설치하거나 본문을 다른 이름 아래 옮기지 않는 것이 좋습니다. [OpenAI 공식 Skill 작성 문서](https://developers.openai.com/plugins/build/skills), 확인 2026-10-02.

## 결과를 해석하는 법

계산상 시간 여유가 있어도 실제 시험 PASS는 아닙니다. 준비 확인 이후 화면·연결·후보가 바뀌면 해당 조건만 갱신합니다. 사용자에게 이미 받은 유효한 승인을 이유 없이 다시 요구하지 않으며, 실제 지원 여부가 확인되지 않은 자동 트리거나 장치 동작을 가정하지 않습니다.

브라우저가 막혔다는 이유로 이 Skill을 설치해도 접속 권한이 달라지지 않습니다. 연결 도구와 인증·권한 문제는 해당 공식 도구의 범위에서 따로 해결해야 합니다.
