- 이 저장소는 지침 파일 모음입니다. 브라우저 연결·포트·권한을 고치는 프로그램이나 장치 제어 도구가 아닙니다.
- 전역 설치, 설치 후 자동 선택, 실제 장치 시험, 사용자 시간·토큰 절감은 미검증입니다.

## Skill 설치

먼저 [설치·사용 안내](docs/usage.md)를 읽고, 파일 지정 방식으로 시험할 수 있습니다. 전역 설치를 원하면 Codex에 아래처럼 요청하세요.

```text
https://github.com/jeonbyungryong/CODEX_NEW_SKILLS_261002 의
skills/coordinate-device-validation 을 검토한 뒤 설치해줘.
같은 이름의 기존 Skill이 있으면 덮어쓰지 말고 차이를 먼저 알려줘.
```

설치 요청 예시일 뿐, 이 저장소를 열거나 다운로드한 것으로 설치가 완료되지는 않습니다. 설치 도구의 결과와 실제 선택 여부를 별도로 확인해야 합니다.

## 기본 사용 흐름

1. 시험 목표, 승인 범위, 현재 기기·화면·연결 상태를 제공합니다.
2. 준비·행동·관측·종료를 짧게 정리하고 시간 예산을 검토합니다.
3. 조건이 맞을 때만 실행합니다. 범위 변경이나 새 권한이 필요한 대안은 조건부로 남깁니다.
4. 사용자 실물 관측과 agent 로그를 구분해 결과·복귀 상태를 기록합니다.

설치되어 사용 가능한 환경에서는 `$coordinate-device-validation`을 요청에 포함할 수 있습니다. 단순 문장 수정·일반 상태 보고·단위시험에는 이 Skill을 사용할 필요가 없습니다.

## 자료와 백업

- `skills/`: 실제 지침과 필요한 참조만 포함합니다.
- `docs/`: 설계, 사용법, 검증 범위와 알려진 한계입니다.
- `evals/`: 가상 사례와 비교 응답입니다. 실제 장치 로그가 아닙니다.
- 과거 상태는 Git 커밋과 작업 브랜치로 보존합니다. 기존 저장소 파일을 통째로 지우거나 강제 push하지 않습니다.

## 꼭 지킬 사항

- 프로젝트 승인 기준이 우선입니다. 특정 제품의 리셋 허용 기준을 다른 제품에 그대로 적용하지 마세요.
- 시간 부족·분기 불명·미실시를 PASS로 바꾸지 마세요. 복구 성공은 원인 규명과 별개입니다.
- 실제 조작은 제공된 도구·권한·복구 범위 안에서만 수행합니다. 이 Skill 자체는 권한을 부여하지 않습니다.
- 인증정보, 서명 키, APK, 회사 내부 원본·장치 식별정보를 이 저장소에 넣지 마세요.
- 별도의 라이선스는 아직 지정하지 않았습니다. 공개 저장소라는 이유만으로 특정 오픈소스 라이선스가 적용된다고 간주하지 마세요.
