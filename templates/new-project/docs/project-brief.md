# 프로젝트 초기 기획

상태: [초안/합의됨] · 기준일: [날짜] · 결정 담당: [역할 또는 미정]

이번 작업에 필요한 항목만 채운다. 해당하지 않는 절은 삭제하거나 해당 없음으로 표시한다. `[입력]`은 확정값이 아니며, 모르는 값은 미정 결정으로 연결한다. 스킬 적용 여부는 프로젝트 `AGENTS.md`의 조건으로 판단한다.

## 목적과 성공

- 해결하려는 문제: [누가 어떤 상황에서 겪는 문제인가]
- 핵심 사용자와 사용 환경: [사용자·권한·기기·네트워크 중 관련 항목]
- 가장 중요한 사용자 동작: [입력부터 실제 결과까지 한 문장]
- 이번 완료 상태와 관측 방법: [사용자가 무엇을 할 수 있고 어떻게 확인하는가]
- 이번 산출물: [기획/명세/구현/검토/회고 중 범위와 결과물]

## 먼저 확인할 경로

정상 입력 → 실제 결과 → 필요한 저장·응답 → 가장 중요한 실패 → 복구·해제 중 이 제품에 존재하는 단계를 연결한다. 단순 도구에 불필요한 저장·인증·장치 단계를 추가하지 않는다.

| 우선 작업 | 사용자 영향·위험 | 먼저 확인할 가정 | 최소 관측과 종료 조건 |
| --- | --- | --- | --- |
| [작업] | [이유] | [가정 또는 미정] | [관측] |

## 범위 변경과 다음 행동

- 다음 작은 작업과 필요한 입력: [내용]
- 추가 조사가 바꿀 결정과 조사 상한: [필요할 때만 작성]
- 변경된 완료 기준·제외 범위와 결정 근거: [변경이 있을 때만 작성]
- 템플릿 출처 버전·프로젝트 수정 여부: [선택. 가져온 저장소 ref/commit 등]

기획 완료는 목적·범위·핵심 경로·중요한 미정의 처리 방법이 합의된 상태다. 이 문서만으로 실제 제품의 구현·시험이 완료된 것은 아니다. 상세 요구는 [명세](requirements.md)에 연결한다.
