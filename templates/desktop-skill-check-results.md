# Desktop 수동 스킬 확인 기록 — 빈 양식

이 파일은 **미실행 양식**이다. 임시 시험 repo 밖의 로컬 파일로 복사해 작성한다. 안내문·이 양식·기대 대상표를 암묵 선택 요청에 첨부하지 않는다. 공개 원본에 실제 값이나 개인 정보를 자동 업로드하지 않는다.

절차: [Desktop 수동 확인](../docs/desktop-manual-skill-check.md). 복사 후 상대 링크가 동작하지 않으면 원본 GitHub 안내를 연다.
